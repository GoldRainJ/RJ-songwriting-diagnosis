# RainJ-diagnosis · 写歌卡点诊断

> 一套基于「歌路大学」多年写歌教学经验蒸馏的诊断框架：**问诊消解你的卡点，体检保护你作品的下限。**

---

## 这是什么

写歌卡点诊断 skill——帮你（或帮你的学员）判断「卡在哪里、为什么卡、该怎么破」。

核心不是教乐理，是**消解卡点**：学员说「我卡在 X」，十次有九次 X 不是真卡点，背后藏着一个归因错误。

它包含：

- **8 条诊断公理**：没天赋是伪命题 / 撞车是常态 / 创作与批判互斥 / 不想写≠不会写 / 平均用力是最大的坑 / 乐感差是主体性被压抑 / 先有感知再有经验 / 卡点真因不在自述处
- **问诊模式**：消解漏斗（归因检测 → 语言陷阱 → 假设错误 → 信息充分）
- **体检模式**：六项检验（动机 / 主副歌结构 / 音域音色 / 音准 / 挤卡 / 和声 voicing）
- **28 条实战案例 + 归因知识库**

## 怎么用

### 方式 1：Claude Code（原生）

把整个目录放进 `~/.claude/skills/`（全局）或项目 `.claude/skills/`，然后用 `/RainJ-diagnosis` 触发。

### 方式 2：国内大模型智能体（豆包 / 元宝 / 千问 / 扣子）

1. 打开对应平台的「创建智能体」入口
2. 把 `prompt.md`（或 `prompt-lite.md`）的内容粘进「人设 / 提示词」框
3. 把 `写歌诊断内联案例库.md` 和 `写歌诊断归因知识库.md` 上传为「知识库」
4. 发布，开始对话

各平台入口：
- **豆包**：App「更多」→「智能体」→ 创建
- **元宝**：App 内创建自定义智能体
- **千问**：阿里云「百炼」平台创建智能体
- **扣子 Coze**：创建 Bot（支持知识库）

### 方式 3：DeepSeek Harness（DSH）

把 `prompt.md` 的内容作为 preset 的 `persona` 字段，通过 DSH 的 Agent Preset 加载。

### 方式 4：API

把 `prompt.md` 内容作为 `system` 消息，调任意支持 system prompt 的 API（DeepSeek / 千问 / 豆包等）。

## 定位与边界

本 skill 服务于「**普通人写自己唱的好歌**」——自己写、自己唱的人。

**不包含**：艺考 / 考学、卖歌、项目竞标中标类。
